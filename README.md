# eli5-flow

Explain how anything works like I'm 5 — built around **cause and effect**.

```
/eli5-flow why does bread rise
```

Produces a HTML artifact with big pictures and few words that walks through the topic as one clear chain:

- **The chain** — numbered steps where every arrow says *why* it leads to the next
- **Snap a link** — "what if this step didn't happen?" to show which causes really matter
- **Easy to mix up** — common misunderstandings, side by side with what's really going on

Inspired by [eli5](https://github.com/dreambigou/eli5). Unofficial — not affiliated with the original eli5 plugin or its authors.

## Install

```
/plugin marketplace add prgmr99/eli5-flow
/plugin install eli5-flow@eli5-flow
```
